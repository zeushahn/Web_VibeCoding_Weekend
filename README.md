# Web_VibeCoding_Weekend
(산대특) AI 바이브코딩을 활용한 웹서비스 제작 실무     
교육기간 : 2026년 10월 04일 ~ 2026년 11월 07일.      

연락처 : kennysy@naver.com



    HTML 웹페이지에서 사용자가 텍스트를 자유롭게 편집할 수 있는 리치 텍스트 에디터(Rich Text Editor)를 만들어 주세요.
    
    다음 기능을 구현해 주세요.
    
    1. 글자 크기 변경 (12px~48px)
    2. 굵게(Bold), 기울임(Italic), 밑줄(Underline), 취소선
    3. 글자 색상 및 배경 색상 변경
    4. 왼쪽, 가운데, 오른쪽 정렬
    5. 글꼴(Font Family) 변경
    6. 제목(H1~H6) 및 일반 문단 설정
    7. 글머리 기호 및 번호 목록
    8. 실행 취소(Undo), 다시 실행(Redo)
    9. 선택한 텍스트에만 서식 적용
    10. HTML 소스 보기 및 편집
    
    구현 조건
    - HTML, CSS, JavaScript 사용
    - 편집 영역 상단에 MS Word와 유사한 서식 도구 모음 배치
    - 텍스트를 마우스로 선택한 후 서식을 적용할 수 있도록 구현
    - 편집 결과를 HTML 형식으로 저장하고 다시 불러올 수 있도록 구현
    - 가능하면 오픈소스 에디터인 Tiptap 또는 Quill 활용
    - 한글 입력 및 편집 지원
